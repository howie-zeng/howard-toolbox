# Glossary — Tuckman & Serrat (2022)

Terms explained while reading. Keep entries short: meaning, why it matters, chapter.

| Term | Meaning | Ch. |
|---|---|---|
| Gross horizon return | Holding-period return from ending full price + coupons + coupon reinvestment, divided by initial full cost. No financing. | 3.1 |
| Net horizon return | Gross minus financing interest; denominator still the full purchase price. Book calls this return on balance sheet. | 3.1 |
| Return on capital | Same numerator as net return, but denominator is the haircut/equity posted. Leverage scales RoBS. | 3.1 |
| Realized / horizon return | Book: ex-post holding-period return using end-horizon market price, coupons, reinvestment. Does not require a sale. Street accounting: price piece is realized only if sold; else MTM. | 3.1 |
| Yield to maturity (YTM) | Single rate y such that discounting remaining CFs at y recovers market price. 1-1 with price given the schedule. UST quoted s.a. as (1+y/2). Quote/IRR, not expected return unless y stays put and coupons are reinvested at y. | 3.2 |
| Par / premium / discount | On a coupon date: coupon rate = y → P=100; coupon > y → premium; coupon < y → discount. Compare c to this bond’s y, not y to the risk-free rate. | 3.2 |
| Pull to par | At a fixed yield, premium/discount prices trend toward 100 as maturity shortens. Actual path follows realized market yields. | 3.2 |
| Why a bond’s y moves | New P or new remaining CFs ⇒ new y. Curve shift, spread vs the curve, rolldown. If the curve is flat and stuck, this bond’s y can stay constant while price still pulls to par. | 3.2 |
| Yield vs realized return | Ex-post return = initial y iff coupons reinvested at that y and ending y is unchanged (App. A3.2). Otherwise y is only the quote/IRR, not the holding-period return. | 3.3 |
| Reinvestment risk | Intermediate coupons rolled at a rate ≠ initial y. Survives even if held to maturity. Rates down → this piece worse. | 3.3 |
